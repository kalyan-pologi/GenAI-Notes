Managing context: /compact vs /clear

When a session's context fills up or quality starts to drop, you have two tools. The rule of thumb: same task → compact (keeps a summary, less history), new task → clear (fresh reset). When unsure, compact is the safer default.

After either action, run /context to confirm what was actually dropped — this is the "Detect → Decide → Fix" loop for keeping context clean.
